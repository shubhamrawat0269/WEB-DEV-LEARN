# In this lecture, we are going to study about I/O operations and Nodejs Special ability for handling I/O operations asynchronously i.e. async I/O

1. I/O operations are considered to be time consuming.
2. If a program waits for every I/O task to finish, it becomes slow.
3. Node.js does not wait for I/O tasks.

4. This is called:
  - Non-blocking I/O
  - Asynchronous programming

5. Why Node.js Is Fast for I/O
Because it:

does not waste time waiting
can handle many users together
efficiently manages network requests
