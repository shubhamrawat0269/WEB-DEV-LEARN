# in this lecture, we study about managing file permissions

1. We have three types of permissions : Read, Write and execute.
2. To Change file permissions, Go to reveal in File Explorer > properties > securtiy tab
and then choose the user. 
3. User can change read, write permissions as per their need.
4. On windows, read and execute permission are combined.
5. We can also see permissions of a file inside a terminal. 
6. Using bash terminal to run command ls -l , didn't show clear result of permissions,
7. Using Powershell terminal, we can also manipulate permissions of file.
