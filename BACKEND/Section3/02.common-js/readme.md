1. require() is a function take a path as an argument and return the object 
2. By path, it means the path of the file which we want to include.
 - Path needs to be correct otherwise, it throws an error.
 - Path can be absolute or relative.

3. By Object, it means module.exports object which is by default empty.
4. You can also perform array, object destructuring while importing.

Note : -> It's recommended to use es6 modules over common js modules.
