# in this lecture, we are going to study about DataStreams.

1. Whenever we start a **process** (or application), it is attached with three datastreams.
2. Three datastreams are :
   A. stdin stream (duplex [readable stream heavy] stream). It is by default connected with **keyboard** if we start our process with terminal. For Example : **Bash Stream**
   B. stdout stream (duplex [writable stream heavy] stream)
   C. stderr (duplex [writable stream heavy] stream)
