1. If you put . after typing google.com For Ex -> youtube.com. , what happen
2. It'll still redirect to the same url as typing google.com does.

3. Full Domain Name is not www.google.com  but , **www.google.com.**
4. Domain name is divided into 4 layer:
  A. Root Level Domain (RLD) represents (.)
  B. Top Level Domain (TLD) represents (com)
  C. Second Level Domain (SLD) represents (google)
  D. Sub domain represents (www)

5. Responsiblity of a domain name is to find and fetch the corresponding IP across the network
6. Root Level Domain holds record of Top level Domain to search for IP address effectively.

7. Domain name is limited to 253 characters only
